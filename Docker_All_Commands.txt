MLOPS PRACTICAL - DOCKER COMMANDS
===================================

Based on MLOps Lab Exercise No. 5 - Exploring Containerization and
Application Deployment with Docker.

Docker is used to package applications and their dependencies into
portable and isolated containers.


IMPORTANT BEFORE PRACTICAL
--------------------------

On Windows:
1. Open Docker Desktop.
2. Wait until Docker Engine is running.
3. Then open PowerShell / Git Bash / VS Code terminal.
4. Run Docker commands.

After finishing:
- Stop/remove test containers if required.
- Close Docker Desktop if you are completely finished.


1. CHECK DOCKER INSTALLATION
----------------------------

docker --version
    Displays the installed Docker version.

docker compose version
    Displays the Docker Compose version.

docker info
    Displays detailed Docker Engine/system information.


2. DOWNLOAD / MANAGE IMAGES
---------------------------

docker pull ubuntu
    Downloads the Ubuntu image from Docker Hub.

docker pull hello-world
    Downloads the hello-world image.

docker images
    Lists all Docker images available locally.

docker rmi image-name
    Removes a Docker image.


3. RUN CONTAINERS
-----------------

docker run ubuntu
    Creates and runs a container from the Ubuntu image.

docker run hello-world
    Creates and runs a hello-world container.
    Used to verify that Docker is working.

docker run -it ubuntu bash
    Runs Ubuntu interactively with a terminal.

docker run -it --name mycontainer ubuntu bash
    Creates a named Ubuntu container and opens an interactive terminal.

IMPORTANT:
-it = interactive terminal
--name = assigns a container name


4. CONTAINER MANAGEMENT
-----------------------

docker ps
    Lists currently running containers.

docker ps -a
    Lists all containers, including stopped containers.

docker start mycontainer
    Starts a stopped container.

docker stop mycontainer
    Stops a running container.

docker restart mycontainer
    Stops and starts the container again.

docker logs mycontainer
    Displays the output/logs generated by the container.

docker rm mycontainer
    Removes a stopped container.


5. NGINX WEB SERVER
-------------------

docker pull nginx
    Downloads the Nginx image.

docker run -d --name nginx-server -p 8080:80 nginx
    Runs an Nginx container in detached mode and maps:
    Host port 8080 -> Container port 80.

Open in browser:
http://localhost:8080

docker logs nginx-server
    Displays Nginx container logs.

docker stop nginx-server
    Stops the Nginx container.

docker rm nginx-server
    Removes the Nginx container.

IMPORTANT:
-p 8080:80
    8080 = host port
    80   = container port


6. DOCKERFILE
-------------

A Dockerfile contains instructions used to build a custom Docker image.

Typical Dockerfile:

FROM ubuntu
RUN apt update
RUN apt install -y python3
WORKDIR /app
COPY app.py .
CMD ["python3", "app.py"]

Meaning:

FROM
    Selects the base image.

RUN
    Executes commands while building the image.

WORKDIR
    Sets the working directory inside the image/container.

COPY
    Copies files from the local project into the image.

CMD
    Command executed when the container starts.


7. BUILD A CUSTOM IMAGE
-----------------------

docker build -t my-python-app .
    Builds an image from the Dockerfile in the current directory.

-t my-python-app
    Gives the image a name/tag.

.
    Uses the current directory as the build context.

docker images
    Verifies that the image was created.


8. RUN CUSTOM IMAGE
-------------------

docker run --name my-python-container my-python-app
    Creates and runs a container from the custom image.

For a web application with port mapping:

docker run --name my-python-web -p 8000:8000 my-python-app

Then open:

http://localhost:8000


9. DOCKER VOLUMES
-----------------

Docker volumes provide persistent storage independent of a container.

docker volume create myvolume
    Creates a Docker volume.

docker volume ls
    Lists Docker volumes.

Example of mounting a volume:

docker run -it --name volume-container -v myvolume:/data ubuntu bash

Meaning:
-v myvolume:/data
    Mounts the Docker volume myvolume at /data inside the container.

A file created inside /data remains in the volume even after the
container is removed.

docker volume inspect myvolume
    Displays volume details.

docker volume rm myvolume
    Removes the volume.


10. DOCKER NETWORKING
---------------------

docker network ls
    Lists available Docker networks.

docker network create mynet
    Creates a custom Docker network.

docker network inspect mynet
    Displays network configuration/details.

Example:

docker run -d --name container1 --network mynet ubuntu

    Runs a container connected to the custom network.

Docker containers connected to the same network can communicate
through the Docker network.


11. DOCKER IMAGE EXPORT
-----------------------

docker save -o hello-world.tar hello-world:latest
    Exports a Docker image to a .tar file.

docker save -o ubuntu.tar ubuntu:latest
    Exports the Ubuntu image.

docker save -o my-python-app.tar my-python-app:latest
    Exports a custom image.

docker save -o nginx.tar nginx:latest
    Exports the Nginx image.


12. DOCKER IMAGE IMPORT
-----------------------

docker load -i hello-world.tar
    Imports an image from a .tar file.

docker load -i ubuntu.tar
    Imports the Ubuntu image.

docker load -i my-python-app.tar
    Imports the custom Python image.

docker load -i nginx.tar
    Imports the Nginx image.

docker images
    Verifies the imported image.

14. DOCKER IMAGE VS CONTAINER
-----------------------------

IMAGE
    Read-only package/template containing the application and dependencies.

CONTAINER
    Running/created instance of an image.

Remember:

docker pull
    Image comes from Docker Hub.

docker run
    Image -> Container.

docker build
    Dockerfile -> Custom Image.

docker stop
    Stop Container.

docker rm
    Remove Container.

docker rmi
    Remove Image.

26. EXAM GOLDEN SEQUENCE
------------------------

If asked to create and run a Docker application:

1. Start Docker Desktop.

2. Create Dockerfile.

3. Build image:

docker build -t my-python-app .

4. Check image:

docker images

5. Run container:

docker run --name my-python-container my-python-app

6. Check container:

docker ps -a

7. View output/logs:

docker logs my-python-container
